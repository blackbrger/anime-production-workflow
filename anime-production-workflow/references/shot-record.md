# 镜头记录与阶段证据

复杂或多轮制作时，用项目已有记录承载这些信息。一次低风险修帧可只在工作笔记中保存版本、范围和复查结论；不要求为了填表新建一套管理系统。

## 最小镜头记录

按需使用下列 Markdown 结构，示例字段需填写真实值；未知项直接写未确定，不虚构通过记录。

```text
镜头与版本：
任务范围：新制 / 局部修订 / 诊断
用户约束：风格、角色母版、片长/切点、声音、交付、明确的确认点
表演目的：角色想做什么、注意谁、发生何种变化
主要难点：
采用方法与理由：
当前阶段：
帧率与编号：局部或全片；0 或 1 起算；区间端点约定

动作事件：时间/帧 → 姿势 → 接触/遮挡/道具状态 → 表演目的
稳定部分：固定背景、静物、身份特征或已通过动作
候选来源：实际素材路径、生成任务或源工程 revision
试制依据：本轮样板 / 已通过且难度相当的既有样板 / 低风险无需另制
证据：实际媒体、风险区间局部序列、切点对照及相同版本标识

计算：未开始 / 完成 / 失败 / 不适用
采用：未采用 / 工作版已采用 / 不适用
技术：通过 / 未通过 / 未验证 / 不适用
视觉：通过 / 未通过 / 未验证；必须注明范围
用户认可：未请求 / 待反馈 / 明确接受 / 明确拒绝
缺陷：位置、可见症状、影响、原因假设
本轮变化：针对哪个原因、改变什么、保留什么
复查：旧问题是否解决、新问题、未修改部分的检查依据
下一步与方法复审点：
```

已采用候选可以视觉未通过。视觉通过也不等于用户已认可。未完成声音任务时不应因画面通过把有声成片整体判为完成。

需要看完整填写过程或比较通过、返工与风格允许时，读 [执行案例与验收对照](worked-examples.md)。其中结果均为教学设定，不能迁移为当前项目的证据。

## 哪些检查支撑哪些结论

| 检查 | 可以支持 | 不能支持 |
| --- | --- | --- |
| 单张关键姿势 | 这一姿势的结构、剪影、画风 | 动作节奏、连续性或整片流畅 |
| 全动作目标速度预览 | 动作可读性、节奏与整体连续性 | 自动排除快速经过的手指、叉齿或接缝错误 |
| 高风险区间逐帧局部图 | 所查帧的轮廓、接触、遮挡、清晰度 | 未覆盖区域通过；静帧天然证明正常速度效果 |
| 曝光、像素重复和轨迹数据 | 定位停留、位移跳变与可能的漂移 | 以独立画面数量或阈值替代艺术判断 |
| 实际导出解码、音频和字幕检查 | 规格、可解码性、时点、字幕边界 | 角色表演好看、声音有情感、接触动作正确 |
| 源版本或像素一致 | 相应范围可以复用该版本已有证据 | 原先未通过的保留段自动转为通过 |

工具只能提供离散截图或抽帧时，保留这个证据边界；可以继续做结构、曝光和源数据检查，不能伪称连续实时观看。主观听感须有可用音频检查条件；文件有音轨不等于已经听过。

## 风险与严重性

只记录对本任务有意义的风险，并覆盖完整风险区间，不能只挑好看的端点：
- 关节、持物点或支撑接触改变；
- 手掌翻转、肢体交叉、新轮廓显露；
- 食物入口、物体转交、显隐或状态改变；
- 固定背景与局部重画的接缝；
- 动作区间接回停留、循环末首、镜头剪切；
- 改时序后与声音、字幕或判定事件的关系。

**阻断项**是妨碍用户要求成立的错误，例如物体数量跳变、肢体断接、不可解释的位移、关键动作缺失。先修它或调整方法，不能扩展依赖它的最终制作。

**可保留限制**需要根据用途判断，例如有意义的停留、风格允许的拍二、主动剪辑省略。不能为了套流程把这些一律视为失败；用户明确要求粗样片时可保留缺陷并准确标注。

## 修订后的复查范围

最小范围是修改段、进入/退出边界、影响到的固定区域，以及相邻镜头的动作阶段。切点前后留足理解行为的时间，长度按动作决定；跨镜道具和视线用相邻画面对照。

单帧清线等微小修补，先确认所用 cel、贴图或实例的共享引用，必要时隔离该帧再改。同一已验收基线的运动结构没有变化时，可复用原动作验收；本轮检查修补像素、受影响引用与相邻帧即可，不强制重新播放所有镜头。

精确保留像素的要求以源图为准：比较修补区域外与未修改帧的像素一致性，并单独核对曝光未变。重新编码的有损视频用观看和解码规格检查，不能拿它替代源图像素相等的验证。

曝光或节奏变化还要复查完整动作；局部像素修补若没有改时序，可复用已验证的计时信息。原风险类别没有改变时仍需检查对应部位，不能用“只改几帧”免除接缝检查。

最终报告按“观感与遗留 → 文件与版本 → 实际检查 → 下一步”组织。新候选和上一稳定版本均保留，避免覆盖后失去同帧比较依据。
