# 制作方法与返工判断

用于选择首次制作方法，或同类缺陷反复出现时。围绕当前动作与输出约束做最小必要比较，不因能调用某工具就选择它。

## 依据动作选方法

| 动作或问题 | 合适的起点 | 需要防止的误用 |
| --- | --- | --- |
| 固定构图的眼神、表情、小幅转头 | 局部替换原画或有合适素材的分层变形 | 为填时长随机换注视点；用变形推断不存在的侧脸 |
| 手持刚性物体沿稳定路径运动 | 手臂/握持关系与道具独立控制，必要时用三维代理定位 | 道具随软组织拉伸；手与道具各动各的；把平面旋转当成有透视变化的完整动作 |
| 手掌翻转、握法改变、入口/转交遮挡 | 补可信的中间与接触原画，或验证合适的绑定/三维机制 | 跨缺失轮廓直接增加光流帧；用透明淡化表达吞咽或物体转交 |
| 端点已经连续的小幅变化 | 原画曝光、短跨度插值或部件插值，按画风比较 | 因插值成功就跳过手、眼、线条和固定区检查 |
| 允许整体生成的短镜头 | 有稳定参考和明确单一行为的视频生成候选 | 默认跨镜角色/道具一致；把整体看似顺滑误当接触正确 |
| 长期复用、多角度、复杂接触 | 评估二维绑定、三维代理或完整三维角色的投入 | 为一次局部修帧擅自把整片改为三维；把建模完成等同于画风通过 |

混合制作可以只约束道具与手臂，脸、头发或背景继续用二维。不要求“全程生成”“全程手绘”或“全片一种技术”；成片的视觉语言和动作连续性仍要统一。

分层需要补出被遮住的底图和替换姿势。没有素材时先验证少量关键部件，不能把“一张图自动拆开并绑定”记作已完成能力。用户要求逐帧重绘时，简单切片旋转不能冒充同一种交付。

## 短动作试制

选最能决定方法是否可行的片段，覆盖真实难点和进入/退出状态。例如吃东西要看到持物靠近、接触遮挡、空道具退出；只有人物眨眼并不能验证此方法。

粗动作先确定路径与节奏，随后在同一区间验证必要的线条、材质与合成。线稿运动通过只放行相应阶段，不证明最终清稿稳定。试制可以成为成片的一部分，不必额外重做一条展示片。

只有路线存在实质不确定性时才做两种方法对照。保持角色、构图、主要事件、时长范围与观看尺寸可比；改变的方法和额外成本明确记录。候选数量服从预算与证据，不先生成一大批再挑，也不把某一次好结果视为可稳定复用。

比较依据：
- 角色身份、轮廓和细节在运动中是否稳定；
- 手/道具接触、物体数量、遮挡与状态变化是否可信；
- 动作意图、起落节奏与停留是否可读；
- 修改一个指定问题时，能否保护其余部分；
- 达到可采用质量实际需要多少生成、补画与审查工作。

## 按原因返回制作环节

| 观察到的症状 | 先核对什么 | 有效返工方向 |
| --- | --- | --- |
| 清晰但一顿一跳 | 曝光表、相邻位移、起动和收势时间 | 重排曝光与路径，必要时补姿势；先排除解码/播放异常，不能仅凭感觉归因设备 |
| 重影、半透明手或双道具 | 两端轮廓与握法是否对应，是否跨遮挡变化 | 补接触/中间姿势，分层约束或手工清理；缩小可信插值范围 |
| 静止区域晃动或脸型漂移 | 是否整图重生成，局部遮罩是否覆盖过大 | 固定底图、缩小可动范围、校正接缝；不用全图模糊掩盖 |
| 眼睛乱瞟、动作忙但无意义 | 当前注视目标与角色念头 | 删除无目的动作，重新安排有因果的观察与回应 |
| 切镜后动作倒退或持物状态突变 | 上镜末段和下镜起段的动作阶段与道具状态 | 匹配动作；或设计清楚的时间省略/插入镜头，不强行光流过渡 |
| 图像顺滑但像软胶 | 刚性物体、结构体积和形变方式 | 独立道具/约束、替换原画，按合适透视重新画形 |
| 多次修正无可见改善 | 失败原因是否真的改变，是否仍依赖同一能力缺口 | 启动方法复审，先做更可控的短段；不要通过降低验收标准“解决” |

方法复审后的替代必须仍服务用户的目标。替代可以是补画、约束运动或可控合成；若只剩剪掉用户指定动作或改变画风，说明具体取舍并等待该必要决定，同时推进不受影响的已授权工作。

## 局部修订与示例的适用边界

删除变形帧后仍要检查并修正运动间距；一个动作阶段的局部改善不能代表其他保留阶段已经通过。单个片段的失败不能证明所有停留、有限动画、光流或整图生成都不可用。

片长、每镜时长、帧率、角色设定与声音方案应依据当前项目的用户要求确定。不要照搬示例的具体帧号、硬编码素材路径，或自动为每个角色加一套相同表演。
