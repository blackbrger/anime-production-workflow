# 前期创作、声音与交付

用于从头制作、改变故事或剪辑、处理声音、交付可编辑工程。已有合格剧本、声音或工程记录时直接沿用；局部清线不需要重新走这些步骤。

## 把故事变成镜头

先从用户要求或现有剧本整理一句话：谁想做什么，受到什么影响，最终发生什么变化。气氛短片也可以围绕观察、情绪或关系变化组织，不强行加入冲突和对白。

把叙事拆成必要节拍，再为每个节拍选择观众需要看见或听见的信息：

| 决定 | 最小产物 | 检查点 |
| --- | --- | --- |
| 叙事与表演 | 节拍列表：意图 → 行为/声音 → 结果或反应 | 关键反应有原因，信息出现顺序可理解；不只罗列动作 |
| 镜头作用 | 每镜一句目的、主体、景别、进入/退出状态、预计时长 | 切镜带来信息、情绪或观看重点；同一意义可在一个镜头完成时，不为凑数量切碎 |
| 镜头空间 | 人物与道具位置、视线/运动方向；复杂场面用简单俯视草图 | 观众能理解谁看谁、谁拿什么、相对位置如何变化 |
| 动态分镜 | 粗画、暂定或采用声音、镜头切点与关键动作事件 | 按目标速度能读出节拍；依赖对白或音乐的动作有足够时间 |

分镜时同步安排角色与场景参考：同一人物在各景别的身份特征、同一道具的形状与尺寸、构图中的明暗重点。已有风格与母版可直接引用；需要实质改变时才增加美术探索。

多人物场面尤其检查：建立关系的镜头或其他空间线索是否足够；正反打视线是否能对上；过切点时动作阶段、持物者、行进方向与遮挡是否可接。越轴、方向反转或时间省略可以是创作选择，但需用可读的移动、重新建立空间或明确的剪辑语境支持，不能把轴线规则当机械禁令。

若现有构图无法清楚表现关键接触，先改构图、景别或动作安排，再投入精细绘制。用户锁定构图时，在约束内试出可行方案，确实冲突再提出具体取舍。

## 声音在何时进入

区分对白、旁白、音乐、环境声和拟音，标明来源/版本、临时或采用状态、时间基准与相关事件。只制作用户要求或作品需要的声音；无声短片无需补齐所有声部。

| 环节 | 声音工作 | 对后续制作的影响 |
| --- | --- | --- |
| 剧本与粗分镜 | 确定对白/旁白文本、说话者与意图；需要时用临时读音估时 | 文字长度不能直接代替说话时长；临时音频可用于粗动作，但需标明可能受其变化影响的镜头 |
| 依赖声音的动作精修之前 | 选定实际采用的台词版本、语速、停顿和起止；明确采用状态由谁负责 | 口型、接话、打断、听后反应依赖该节奏；未定稿时可继续背景、粗姿势，以及不依赖对白时点的结构验证、接触原画与可重定时部件，不冒充最终同步 |
| 动态分镜与动作制作 | 先放对时机敏感的拟音提示；若按音乐节拍编排动作，先确定采用音乐及相关段落 | 接触、落地、转交等事件与声音使用同一时间基准；非节拍驱动的配乐可在画面节奏稳定后完成 |
| 画面时序稳定后 | 完成环境声、拟音、配乐剪辑与混合；字幕对照采用台词 | 保留静默与叙事重点，避免配乐掩盖对白；临时占位应替换或明确保留为工作版 |
| 实际导出后 | 检查完整视听关系、声道、截断、字幕和导出同步 | 工程中同步不证明导出同步；实际听过才评价听感 |

“确定采用”是制作依赖，默认沿用现有授权和内部决策，不额外设立用户审批关卡。声音后续变化时，按影响重查口型、动作事件、切点与字幕；不自动重做无关镜头。画面时序变化也要反向检查声音。

混音先服务对白理解、情绪与空间关系：检查爆音、突兀接缝、背景过响、声像与画面关系，以及开头/结尾是否被截断。交付方有响度或格式要求时按其要求测量；没有时不把自定数字伪装成通用合格标准。检测无削波不等于听感良好；只能读元数据时保留听感未验证项。

## 全片检查与打包

全片检查集中在跨镜关系：故事是否读得懂，信息和反应是否给足时间，角色与道具是否延续，视觉重点是否稳定，音乐/对白/拟音是否支持动作，以及片头片尾、字幕与声音是否完整。局部动作都通过仍需检查这些关系。

交付范围沿用用户约定；只要成片时，不强制扩展为可编辑工程交付。

| 约定交付 | 包含什么 | 如何验证 |
| --- | --- | --- |
| 观看版 | 采用版本的影片、要求的字幕或字幕文件 | 打开实际导出，核对规格、时长、画面边界、声画和字幕；结论注明实际看听范围 |
| 可编辑工程（若要求） | 主工程、采用素材、必要的图层/绑定/序列、音频与时间线，及依赖版本说明 | 从交付位置重新打开，检查素材缺失、绝对路径和采用状态；必要时重渲染一个代表区间，区分重开成功与导出可复现 |
| 交接记录（按交付需要） | 仅交观看版时说明文件、版本、检查范围及必要剩余项即可；交工程时再补打开/导出方法、关键约束与依赖说明 | 接手者能够定位实际内容；当前状态与交付文件一致，无需依赖聊天里的隐含选择 |

打包以采用素材为中心；候选与旧稳定版本保留在制作归档中，是否随包交付按需求决定，不能擅自删除。能相对引用时整理为相对路径；必须依赖外部缓存、字体、插件或模型时记录确切依赖及已验证情况。缺少打开条件时可以交付已整理工程，但要明示未重开验证，不能写成可复现已经通过。
