# 执行案例与验收对照

**本文件全部为教学示例，没有实际生成或验收这些媒体。** 版本号、路径、缺陷和结果均用于演示记录方式，不能引用为真实项目证据。实际执行须替换为真实素材与观察；未执行的检查写“未验证”。

按需阅读：[完整制作案例](#完整制作案例递杯与回应)、[单帧清线](#轻量案例只修一帧)、[验收对照](#同一动作的三种验收判断)。示例时长、帧率和制作方法不是默认配置。

## 完整制作案例：递杯与回应

### 用户要求与前期依据

示例请求：“做一条 8 秒的二维短片。甲把杯子递给乙，乙接稳后微笑回应。保留给定人物设定和 8 秒对白轨；交付观看版及可编辑工程。”

以下假设采用 24 fps、两个各 4 秒镜头。全片 F1–F192，以 1 起算，书写帧区间均含两端；F1 从 0 秒开始。镜头二局部 F1 对应全片 F97。音频时间用全片秒数记录，避免音频事件强行取整造成错位。

| 前期项目 | 示例中已确定的内容 |
| --- | --- |
| 叙事节拍 | 甲表达照顾 → 递杯 → 乙确认接稳 → 微笑回应 |
| 镜头 S01 | 0–4 秒，双人中景；甲在画面左，乙在右，杯子由左向右递出；让观众看清交接 |
| 镜头 S02 | 4–8 秒，乙近景；接续乙左手持杯与朝左看甲，靠表情和回答完成关系变化 |
| 空间与状态 | 甲右手先握杯柄；乙左手从杯身下方托握。交接后甲松手，乙继续持杯；切镜不镜像角色，也不突然换手 |
| 对白依据 | 演示采用 `audio/dialogue_v03.wav`，总长 8 秒；甲“给你，慢点喝。”在 0.50–1.50 秒；乙“谢谢。”在 4.50–5.20 秒。此路径为虚构记录，实际工作需核对文件与内容 |
| 声音安排 | 无音乐要求，不新增配乐；粗分镜标注接触时点，需要的衣物轻响待时序稳定后加入。对白节奏已确定，口型与接话精修可据此进行 |
| 美术依据 | 既有角色与杯子母版；杯子保持体积与杯柄方向，透视变化允许；背景和桌面固定 |

粗分镜先验证“递出—接稳—回应”能否在这 8 秒内读懂，以及 S02 开头是否延续 S01 末尾。对白存在不代表全部画面必须对口型：S01 的甲和 S02 的乙分别按其发声片段处理，听者承担反应表演。

### 方法选择与事件表

难点是杯柄附近的手指遮挡与持物责任转移。示例已有角色设定，没有现成三维绑定；首次采用局部替换画，固定背景和身体稳定区域，杯子单独控制。可信端点之间尝试短跨度插值；双手交接需独立接触姿势。

选择理由：需要保持二维画风并能局部改接触；整体生成难以保证指定手部局部修订，完整三维角色投入在本例缺乏复用依据。若已有合格绑定或整体生成样板，选择可以不同。

| S01 局部帧 | 姿势与动作事件 | 接触/道具状态与意图 |
| --- | --- | --- |
| F1–24 | 甲看乙并准备递杯 | 甲右手独立持杯；观众建立人物关系 |
| F25–54 | 杯子递向乙；乙左手抬起 | 杯子仍由甲控制，乙尚未接触 |
| F55–66 | 乙左手接触杯身下方，逐渐接稳 | 两人同时接触；杯柄和手指有可信前后遮挡 |
| F67–78 | 乙承接重量，甲松手撤离 | 杯子控制转为乙；甲离开后不能继续拖动杯子 |
| F79–96 | 杯子收势，准备切镜 | 乙左手稳定持杯；视线与 S02 起始一致 |

本例方法仍有不确定性，试制选 F37–84，覆盖靠近、双手接触、松手及撤离，共 48 帧、2 秒。它是 S01 的制作片段，不额外制作无关展示片；粗动作先过，再检查同段的清稿效果。

### 缺陷定位与实质修订

以下是**虚构观察记录**，展示“位置—症状—原因—修改—复查”的填写方式，不表示实际看过任何影片。

初始 v00 已在交接处出现重影；第一轮修正先缩短可信端点之间的插值跨度，得到 v01。下表继续记录该结果、第二轮补接触姿势的 v02，以及改变方法后的 v03。

| 候选 | 示例观察与原因假设 | 修改或决定 |
| --- | --- | --- |
| S01 v01 | F61–66 在目标速度下出现双杯柄闪动；局部帧显示两个轮廓混合。原因假设：插值跨越手指遮挡变化 | 在接触区补一张关键姿势，缩短插值跨度；其他区间不变 |
| S01 v02 | F63–66 仍出现杯柄重影，接触时双手粘连 | 两轮有针对性的修正仍未解决主要问题，进入方法复审；不再只增加插值数量 |
| S01 v03 | 将 F55–78 改为可信的接触与松手替换画；杯子作为刚性部件随握持关系运动，前后手指用明确遮挡关系合成 | 保留已通过的靠近路径与固定底图；检查 F54/55、F78/79 接缝及全段速度。分层所缺的隐藏区域需要实际补画，不能假设自动存在 |

假设 v03 的目标速度检查已实际完成，记录应说明：“S01 全动作可读，F55–78 未再见杯柄重影；逐帧确认接触与撤离连续，S01/S02 切点持物者、握手与视线一致。”若手头只有局部抽帧，就应改写为：“所查帧结构通过，完整播放仍未验证”，不能照抄前一句。

## 轻量案例：只修一帧

示例请求：“F58 杯柄外多了一条线，只去掉它，其他像素与时序不变。”假设基线 v07 的动作已验收，本轮不涉及轨迹、接触或曝光改变。

1. 读取工程版本与帧映射，确认用户指的是 S01 局部 F58。示例发现它与 F57、F59 共享同一 cel；先为 F58 建立独立副本，避免连带改其他曝光。
2. 保留原帧，限定修补区域清掉多余线；按任务使用合适的图像编辑方式，以局部合成与实际比对满足区域外像素约束。
3. 比较 F58 区域外像素、其他帧源像素及曝光表；查看 F57–59 邻接，确认轮廓不闪跳。查看实际交付，不为微小清线重做最难动作试片、动态分镜或整片验收。

填写示例：

```text
版本与范围：v07 → v08；仅 S01 F58 的杯柄外多余线，源帧修补区内
方法：隔离共享 cel 后局部清线，保留原底图与全部曝光
复用依据：v07 已通过的动作、切点与声音检查；本轮运动结构未变
本轮检查：示例假设修补区外像素与其余源帧相同，曝光未变，F57–59 无新闪线
结论：示例假设局部修补通过；不据此新增整片流畅度或用户认可结论
交付：v08 工程/源帧与约定观看版；有损观看版不宣称解码像素逐点不变
```

如果隔离后发现 F58 的手与杯子本就断接，应如实报告新发现及影响，不能伪称单帧清线解决了它；也不能未经范围判断就重做整段。

## 同一动作的三种验收判断

以下对照都是“甲递杯、乙接稳”的**文字化判例**，用于校准推理，不是视频或图像基准。它能说明判断依据，但不能证明不同执行者的视觉尺度已一致；有真实素材时用同一构图、时长和目标观看条件比较。

| 判断 | 目标速度下能看到什么 | 局部证据与结论依据 | 后续动作 |
| --- | --- | --- | --- |
| 通过 | 杯子靠近、乙接触接稳、甲松手依次可读；杯子看起来有稳定体积，没有抢夺或瞬移的歧义 | 风险帧中握点、遮挡与控制关系连续；切镜前后由同一只手持杯 | 当前动作与已检查范围通过；还需按交付范围完成声音、全片和工程检查 |
| 返工 | 乙还没碰到杯子，杯子先跳到乙手里，或双杯柄闪动抢走注意力；观众难以理解转交 | 缺失接触阶段、混合轮廓或切点持物者冲突；单个瑕疵若只在放大静帧可见，应另判影响，不能自动等同动作失败 | 回到接触姿势、路径或剪辑关系；不以增加总帧数作为修复结论 |
| 风格允许 | 使用拍二与有意停留，甲确认乙接稳后再松手，动作有清晰节奏；并非每帧都动 | 重复曝光服务表演，接触和物体数量仍清楚；若采用主动跳切，时间省略由上下文解释 | 符合用户目标时可通过并记录风格选择，无需强制补到每帧变化 |

“风格允许”是通过的一种理由，不是为错误改名。是否接受取决于用户目标、运动中可读性和局部结构的共同证据；用户已排除某种风格时，不能援引此列绕过要求。
