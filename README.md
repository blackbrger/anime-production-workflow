# 动漫短片制作流程

面向 AI 动漫短片制作的 Codex 技能，帮助你把故事、角色表演、镜头、声音与交付组织成可执行、可检查的制作流程。

**技能名称：** `anime-production-workflow` · **当前版本：** `1.1.0` · **语言：** 中文

从一条新短片开始，或接着修已有镜头，都可以使用这套流程。它关注动作是否可信、前后是否连贯、修改是否有效，让制作进度有实际画面与声音作为依据。

## 适合解决什么问题

| 你的任务 | 技能会引导 Codex 做什么 |
| --- | --- |
| 从想法制作多镜头短片 | 整理角色意图、故事节拍、镜头空间和声音安排，再推进动态分镜与制作 |
| 角色动作僵硬、跳动或漂移 | 检查关键姿势、运动间距、曝光与接触关系，定位应返回的制作环节 |
| 手拿道具、递物、入口等动作反复失败 | 先验证覆盖主要难点的短段，选择补画、分层、绑定或三维约束等可行方法 |
| 多个镜头难以接上 | 核对视线、运动方向、动作阶段、持物状态与遮挡关系 |
| 修一个地方却影响其他画面 | 识别共享素材与修改范围，保护固定区域并检查修改区间两端 |
| 整理成片或交接工程 | 核对导出、声音字幕、采用素材、工程依赖与尚未解决的问题 |

单张静态插画、纯软件开发或只做精灵图打包，不是这个技能的主要用途。

## 快速安装

### 让 Codex 安装

在支持技能的 Codex 环境中发送：

```text
使用 $skill-installer 安装下面 GitHub 目录里的技能：
https://github.com/blackbrger/anime-production-workflow/tree/main/anime-production-workflow
```

安装后，在技能选择器中找到「动漫短片制作流程」，或在请求中写出 `$anime-production-workflow`。如果新技能没有出现，重启 Codex 后再检查。

### 手动安装

下载本仓库，将内层的 `anime-production-workflow` 文件夹整体放入以下任一位置，保留 `agents` 与 `references` 子目录：

| 使用范围 | 安装位置 |
| --- | --- |
| 仅当前项目 | 项目中的 `.agents/skills/anime-production-workflow/` |
| 当前用户的多个项目 | `~/.agents/skills/anime-production-workflow/` |

安装完成后，`SKILL.md` 应直接位于这个技能目录内，避免多套一层同名文件夹。安装位置与发现方式参见 [OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills)。

## 使用示例

以下是可按自己的素材和目标修改的示例请求；时长、画风与制作方法都不是固定要求。

### 开始一条新短片

```text
使用 $anime-production-workflow。

我要制作一条约 12 秒的二维动漫短片：
角色在窗边听到声音，停下手里的动作，转头看到朋友后微笑。
沿用我提供的角色设定，最终交付 MP4。

先整理故事节拍、镜头空间和动态分镜；
如果转头与手部动作存在制作不确定性，先完成覆盖难点的短段试制。
```

### 修订已有镜头

```text
使用 $anime-production-workflow 检查我提供的镜头。

问题是递杯时手指粘连，杯柄有重影。
保留角色设计、总时长与现有音轨。

请定位问题区间，提出原因与修法，并在当前可用工具范围内修订。
复查修改区间、两端接缝和相邻镜头的持物状态。
```

### 只做诊断与方案

```text
使用 $anime-production-workflow，先只做诊断。

这段动作已经补过几轮帧，但看起来仍然跳。
请根据我提供的影片与帧序列，检查关键姿势、曝光、运动间距和接触关系，
说明观察到的问题、原因假设与下一步方案。
本轮先不生成新素材或修改工程。
```

提供现有素材时，说明必须保留的角色设定、片长、切点、音轨和交付格式，会更容易控制修改范围。

## 制作流程

1. **故事与制作依据**：明确角色意图、叙事节拍、镜头作用、空间关系和必要声音。
2. **表演与动态分镜**：用低细节、带时序的预览检查行为与剪辑是否读得懂。
3. **关键动作试制**：制作方法存在不确定性时，先验证最能决定成败的短段。
4. **素材与关键姿势**：确认起止、接触、极限与收势姿势，以及道具和遮挡关系。
5. **过渡与曝光**：分配每张画的停留时间，在适合的区间使用插值。
6. **单镜头与接缝**：检查完整动作、修改区间两端和相邻镜头的连续性。
7. **全片与交付**：检查实际导出的画面、声音、字幕，以及约定交付的工程。

这些阶段表示制作依赖。已有合格素材可以复用，局部小修按影响范围检查；不要求每次任务重走整套流程。

## 这套流程怎样判断进展

- **用实际结果判断质量。** 生成成功、帧数增加或软件测试通过，不能直接证明动画好看。
- **区分不同状态。** 计算完成、素材采用、技术通过、视觉通过和用户认可分别记录。
- **尊重修改范围。** 保留用户锁定的设计、时长与声音，局部修订检查共享引用与接缝。
- **根据失败调整方法。** 同一主要缺陷经过连续两轮针对性修正仍无可见改善时，默认进行方法复审；复审点可按预算和进展调整。
- **说明检查边界。** 只看过抽帧时，不声称已经验证完整连续播放；没有听过音频时，不给听感结论。

## 工具与使用范围

本仓库提供流程指令与参考文档。实际绘图、视频生成、音频制作、工程编辑和渲染，需要当前环境具备相应工具与素材；安装技能本身不会安装这些工具，也不会自动获得模型或服务权限。

流程可按任务配合图像生成、逐帧绘制、Live2D 或 Blender 等方法，不绑定某个视频模型或收费服务。其他专项技能可按需配合使用，没有安装时仍可依据本技能进行规划与检查。

示例中的人物、素材路径和验收记录用于教学，不代表已经生成或验证的实际作品。本仓库发布的是技能文档，不包含私人项目素材、聊天记录或访问凭据。
